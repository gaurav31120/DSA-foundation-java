# F009 — Find Maximum Element

## Problem

Given an integer array, find and return the **maximum element** in the array.

## Examples

### Example 1

**Input:**

```text
[10, 25, 7, 42, 18]
```

**Output:**

```text
42
```

### Example 2

**Input:**

```text
[-10, -5, -20, -3]
```

**Output:**

```text
-3
```

## Requirements

* Implement the solution in Java.
* Traverse the array to find the largest element.
* Do not use `Arrays.sort()`.
* Handle negative numbers correctly.
* Return or print the maximum element.
* Analyze the time and space complexity.
