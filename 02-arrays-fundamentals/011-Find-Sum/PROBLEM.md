# F011 — Find Sum of Array Elements

## Problem

Given an integer array, calculate the **sum of all elements** in the array.

## Examples

### Example 1

**Input:**

```text
[10, 20, 30, 40, 50]
```

**Output:**

```text
Sum: 150
```

### Example 2

**Input:**

```text
[-10, 20, -5, 15]
```

**Output:**

```text
Sum: 20
```

## Requirements

* Implement the solution in Java.
* Traverse the array and calculate the sum.
* Handle positive and negative integers.
* Do not use any built-in method that directly calculates the sum.
* Print the result in the format:
  `Sum: <value>`
* Analyze the time and space complexity.
