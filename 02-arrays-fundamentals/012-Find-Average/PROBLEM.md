# F012 — Find Average of Array Elements

## Problem

Given an integer array, calculate the **average of all elements** in the array.

## Examples

### Example 1

**Input:**

```text
[10, 20, 30, 40, 50]
```

**Output:**

```text
Average: 30.0
```

### Example 2

**Input:**

```text
[5, 10, 15]
```

**Output:**

```text
Average: 10.0
```

## Requirements

* Implement the solution in Java.
* Calculate the sum of all elements.
* Calculate the average using the sum and number of elements.
* The result should support decimal values.
* Do not use a built-in method that directly calculates the average.
* Print the result in the format:
  `Average: <value>`
* Analyze the time and space complexity.
