# F013 — Count Occurrences

## Problem

Given an integer array and a target integer, count how many times the **target element occurs** in the array.

## Examples

### Example 1

**Input:**

```text
Array: [10, 20, 10, 30, 10, 40]
Target: 10
```

**Output:**

```text
Occurrences: 3
```

### Example 2

**Input:**

```text
Array: [5, 2, 7, 2, 9]
Target: 2
```

**Output:**

```text
Occurrences: 2
```

### Example 3

**Input:**

```text
Array: [1, 2, 3, 4]
Target: 8
```

**Output:**

```text
Occurrences: 0
```

## Requirements

* Implement the solution in Java.
* Traverse the array.
* Count every occurrence of the target.
* Handle duplicate values correctly.
* If the target does not exist, return `0`.
* Do not use built-in methods that directly count occurrences.
* Print the result in the format:
  `Occurrences: <count>`
* Analyze the time and space complexity.
