# F014 — Linear Search

## Problem

Given an integer array and a target integer, search for the target using **linear search**.

Return the **index of the first occurrence** of the target.

If the target is not present, return `-1`.

## Examples

### Example 1

**Input:**

```text
Array: [10, 20, 30, 40, 50]
Target: 30
```

**Output:**

```text
Index: 2
```

### Example 2

**Input:**

```text
Array: [10, 20, 30, 40, 50]
Target: 100
```

**Output:**

```text
Index: -1
```

### Example 3

**Input:**

```text
Array: [10, 20, 30, 20, 50]
Target: 20
```

**Output:**

```text
Index: 1
```

## Requirements

* Implement the solution in Java.
* Traverse the array from left to right.
* Return the index of the **first occurrence** of the target.
* Return `-1` if the target does not exist.
* Do not use `Arrays.binarySearch()`.
* Analyze the time and space complexity.
