# F015 — Reverse an Array

## Problem

Given an integer array, reverse the array **in-place**.

The first element should become the last, the second element should become the second-last, and so on.

## Examples

### Example 1

**Input:**

```text
[10, 20, 30, 40, 50]
```

**Output:**

```text
[50, 40, 30, 20, 10]
```

### Example 2

**Input:**

```text
[1, 2, 3, 4]
```

**Output:**

```text
[4, 3, 2, 1]
```

## Requirements

* Implement the solution in Java.
* Reverse the array **in-place**.
* Do not create another array for the reversal.
* Do not use `Collections.reverse()` or a built-in reverse method.
* Print the reversed array.
* Analyze the time and space complexity.
