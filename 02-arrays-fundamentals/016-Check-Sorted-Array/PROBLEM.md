# F016 — Check if Array is Sorted

## Problem

Given an integer array, determine whether the array is sorted in **non-decreasing order**.

An array is sorted if every element is **less than or equal to** the element that comes after it.

## Examples

### Example 1

**Input:**

```text id="3qk6ga"
[10, 20, 20, 30, 40]
```

**Output:**

```text id="d4o8e9"
Sorted: true
```

### Example 2

**Input:**

```text id="dckn8g"
[10, 30, 20, 40]
```

**Output:**

```text id="m2ahz6"
Sorted: false
```

### Example 3

**Input:**

```text id="9yqq9x"
[5]
```

**Output:**

```text id="2lkr8x"
Sorted: true
```

## Requirements

* Implement the solution in Java.
* Check whether the array is sorted in non-decreasing order.
* Equal adjacent elements are allowed.
* Return `true` if sorted; otherwise return `false`.
* Do not use a built-in sorting method.
* Analyze the time and space complexity.
