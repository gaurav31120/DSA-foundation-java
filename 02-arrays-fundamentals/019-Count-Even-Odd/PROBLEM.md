# F019 — Count Even and Odd Elements

## Problem

Given an integer array, count how many elements are **even** and how many elements are **odd**.

An integer is:

* **Even** if it is divisible by `2`.
* **Odd** if it is not divisible by `2`.

## Examples

### Example 1

```text
Input:  [10, 15, 20, 7, 8]

Even: 3
Odd: 2
```

### Example 2

```text
Input:  [2, 4, 6, 8]

Even: 4
Odd: 0
```

### Example 3

```text
Input:  [1, 3, 5, 7]

Even: 0
Odd: 4
```

## Requirements

1. Use Java.
2. Traverse the array once.
3. Count even and odd elements separately.
4. Handle positive, negative, and zero values.
5. Do not create another array.
6. Analyze the time and space complexity.

## Test Cases

