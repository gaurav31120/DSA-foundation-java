# F008 — Traverse an Array

## Problem

Given an integer array, traverse the array from beginning to end and print every element.

## Example

### Input

```text
[10, 20, 30, 40, 50]
```

### Output

```text
10 20 30 40 50
```

## Requirements

* Implement the solution in Java.
* Traverse the array from the first element to the last.
* Print every element in order.
* Analyze the time and space complexity.

## Your Task

Solve the problem independently before looking for any solution.
